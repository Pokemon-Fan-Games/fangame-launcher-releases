API pública

API pública del catálogo

Acceso de solo lectura y sin autenticación al catálogo: juegos, versiones publicadas y estado de desarrollo. Todas las respuestas son JSON.

Qué ofrece y qué no

Ofrece los juegos aprobados con sus datos públicos (título, descripciones, autores, idiomas, etiquetas, portada, capturas y estado), las versiones publicadas de cada juego y el contrato OpenAPI.

No ofrece descargas ni URLs de descarga, datos de usuarios, versiones de betas privadas ni contadores (descargas, puntuaciones, tiempo de juego). Los textos libres se devuelven sin los enlaces que el maker haya pegado en ellos.

La API puede estar desactivada en algunas instancias del backend. En ese caso toda ruta responde 404 con un error JSON.

URL base

Todas las rutas cuelgan de /api/v1/ en https://makers-fangames-launcher.dpserver.es.

Listado de juegos

GET /api/v1/games/

Devuelve los juegos ordenados por id (ascendente), en páginas. Todos los parámetros son opcionales y se pueden combinar.

limit
Tamaño de página: 50 por defecto, máximo 100. Un valor mayor se reduce a 100; un valor no numérico o menor que 1 devuelve 400.
cursor
Valor opaco de next_cursor de la página anterior. Mantén los mismos filtros en cada petición.
status
complete, demo, beta o announced. Se compara con el estado de la versión pública actual del juego.
development_state
active, on_hold o abandoned. Se compara con el estado efectivo, el mismo que devuelve el campo development_state.
tag
Nombre exacto de una etiqueta, sin distinguir mayúsculas.
platform
windows, macos, linux o android. Juegos cuya versión pública actual tiene una build para esa plataforma. Si la instancia no ofrece la plataforma, la lista sale vacía.
updated_since
Fecha o fecha y hora ISO 8601, inclusiva. Sin zona horaria se asume UTC.

Un valor no válido en cualquiera de ellos devuelve 400 con el código invalid_query.

Detalle de un juego

GET /api/v1/games/{id}/

Devuelve el mismo objeto que cada elemento de results. Si el id no existe o el juego no está aprobado, responde 404.

curl "https://makers-fangames-launcher.dpserver.es/api/v1/games/marea-roja/"

Versiones de un juego

GET /api/v1/games/{id}/versions/

Devuelve un array con todas las versiones públicas publicadas, demos incluidas, de la más reciente a la más antigua. No está paginado. Un juego sin versiones públicas devuelve [].

curl "https://makers-fangames-launcher.dpserver.es/api/v1/games/marea-roja/versions/"

Esquema OpenAPI

GET /api/v1/schema.json

Documento OpenAPI 3.0.3 con las rutas, los parámetros y los esquemas de respuesta. Úsalo para generar un cliente o validar respuestas.

curl "https://makers-fangames-launcher.dpserver.es/api/v1/schema.json"

Campos

Juego

id
Identificador público del juego. Es el que va en la ruta.
title, description, short_description
Textos del juego, sin enlaces pegados.
status
Estado de la versión pública actual: complete (completo), demo, beta (en desarrollo) o announced (anunciado, sin versión pública). La versión actual es la más reciente que no es demo; si solo hay demos, la última demo.
development_state
active (activo), on_hold (en pausa) o abandoned (abandonado). Un juego con versión completa pública es siempre active, aunque el maker haya marcado otro estado.
development_note
Nota del maker sobre el estado. Vacía cuando el estado es active.
authors
Créditos públicos indicados por el maker, sin duplicados ni correos electrónicos. Puede estar vacío.
languages
Códigos de idioma ISO 639-1.
tags
Nombres de las etiquetas.
content_hours
Horas de contenido estimadas, o null.
wiki_url
Enlace a la wiki del juego, o null. Nunca apunta a descargas.
adults_only
El juego está clasificado solo para mayores de 18. No oculta la portada ni las capturas.
cover_adults_only
La portada tiene contenido explícito. Cuando es true, cover_url y screenshots no aparecen en la respuesta.
cover_url, screenshots
URL absoluta de la portada (o null) y de las capturas aprobadas. Se omiten si cover_adults_only es true.
announced_milestone
Hito que el maker anuncia para el juego (demo, beta o complete), o null.
planned_release_date
Fecha prevista en formato AAAA-MM-DD, o null.
latest_version
Número de la versión pública actual, o null si el juego está solo anunciado.
updated_at
Fecha del último cambio público del juego: ediciones de la ficha (por el maker o por administración), tags, idiomas, capturas, estado de desarrollo y publicación de una versión pública (demos incluidas). Nunca retrocede.

Versión

version
Número de versión.
status
complete, demo o beta.
published_at
Fecha y hora de publicación, ISO 8601.
notes
Notas de la versión, sin enlaces pegados.
platforms
Plataformas con una build aprobada, variantes de idioma incluidas: windows, macos, linux o android. linux indica una build nativa verificada; android solo aparece en instancias que ofrecen APK.

Límites y buenas prácticas

  • Límite de peticiones. 120 por IP y por minuto, contadas entre todas las rutas. Cada respuesta incluye X-RateLimit-Limit, X-RateLimit-Remaining y X-RateLimit-Reset (segundos Unix en que se reinicia el contador). Al superarlo responde 429 con Retry-After en segundos; espera ese tiempo antes de reintentar.
  • Caché y revalidación. Las respuestas correctas llevan Cache-Control: public, max-age=60, ETag y, cuando procede, Last-Modified. Reenvía el ETag en If-None-Match: si no ha cambiado, la respuesta es 304 sin cuerpo. Una 304 también cuenta para el límite.
  • Sincronización. Recorre el listado completo con cursor la primera vez y guarda la hora de inicio. En las siguientes ejecuciones pide solo updated_since=<esa hora>. Si quieres comprobar un juego concreto, ETag y If-None-Match te ahorran la descarga cuando no ha cambiado.
  • CORS y métodos. Se aceptan GET, HEAD y OPTIONS desde cualquier origen (Access-Control-Allow-Origin: *). HEAD devuelve las cabeceras de GET sin cuerpo. Cualquier otro método responde 405 con Allow.
curl -i -H 'If-None-Match: "3f9a…c1d2"' "https://makers-fangames-launcher.dpserver.es/api/v1/games/marea-roja/"

HTTP/1.1 304 Not Modified
ETag: "3f9a…c1d2"
Cache-Control: public, max-age=60
X-RateLimit-Limit: 120
X-RateLimit-Remaining: 117
X-RateLimit-Reset: 1795283460

Errores

Los errores devuelven JSON con esta forma y no se almacenan en caché.

{"error": {"code": "invalid_query", "message": "Invalid development_state."}}
400 invalid_query
Parámetro de consulta no válido o cursor alterado.
404 not_found
El juego no existe, no está aprobado o la API está desactivada en la instancia.
405 method_not_allowed
Método distinto de GET, HEAD u OPTIONS.
429 rate_limited
Se superó el límite de peticiones. Consulta Retry-After.

Los mensajes (message) están en inglés; usa code para tu lógica.
